👀 CreeperEyes · rund

Animierte „Uncanny Eyes“ auf zwei runden GC9A01-Displays (240×240) mit einem ESP32-C3 Super Mini – direkt aus dem Browser flashen.

Dein Browser kann nicht flashen. Bitte Chrome oder Edge am Computer verwenden. Flashen geht nur über eine HTTPS-Seite.

ESP32 per USB anschließen, Knopf drücken, Port wählen. Falls keine Verbindung zustande kommt: BOOT-Taste gedrückt halten, kurz RESET drücken, BOOT loslassen und dann verbinden.

Du hast einen klassischen ESP32 (nicht C3)? → Installer für ESP32 + GC9A01

Was die Firmware macht

  1. Augen schauen zufällig umher, das Oberlid folgt der Pupille.
  2. Automatisches Blinzeln, die Pupille ändert ständig leicht ihre Größe.
  3. Die Lider des linken Auges sind gespiegelt, jedes Auge blinzelt für sich.
  4. Das Auge wird auf das runde 240×240-Display vergrößert.
Portierung von tooluser/CreeperEyes auf ESP32-C3 + GC9A01 mit LovyanGFX, gebaut mit Arduino-ESP32 3.3. Basierend auf Adafruit „Uncanny Eyes“ von Phil Burgess (MIT) und der Anpassung von Laurent Moll.
