👀 CreeperEyes · rund (ESP32)

Animierte „Uncanny Eyes“ auf runden GC9A01-Displays (240×240) mit einem klassischen ESP32 – direkt aus dem Browser flashen. Gleiche Pins wie beim SSD1351-Installer.

Dein Browser kann nicht flashen. Bitte Chrome oder Edge am Computer verwenden. Flashen geht nur über eine HTTPS-Seite (oder localhost). Dein Browser kann nicht flashen. Bitte Chrome oder Edge am Computer verwenden. Flashen geht nur über eine HTTPS-Seite (oder localhost).

ESP32 per USB anschließen, Knopf drücken, Port wählen. Falls keine Verbindung zustande kommt: BOOT-Taste am ESP32 gedrückt halten, während du auf „Verbinden“ klickst. Mit nur einem Display die Variante „1 Display“ nehmen, dann läuft es doppelt so flüssig.

Wichtig

Diese Firmware ist nur für runde GC9A01-Displays. Für eckige 128×128-OLEDs (SSD1351) gibt es den anderen CreeperEyes-Installer; auf einem GC9A01 zeigt der nur Flackern. Für den ESP32-C3 Super Mini gibt es einen eigenen Installer mit anderen Pins.

Was die Firmware macht

  1. Augen schauen zufällig umher, das Oberlid folgt der Pupille.
  2. Automatisches Blinzeln, die Pupille ändert ständig leicht ihre Größe.
  3. Das Auge wird auf das runde 240×240-Display vergrößert; SPI-Takt 27 MHz.
Portierung von tooluser/CreeperEyes auf GC9A01 mit LovyanGFX (aus dem ESP32-C3-Port abgeleitet), gebaut mit Arduino-ESP32 3.3. Basierend auf Adafruit „Uncanny Eyes“ von Phil Burgess (MIT) und der Anpassung von Laurent Moll.
